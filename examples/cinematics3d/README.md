# Cinematic contract example

Run `python scripts/cinematics3d_example.py` from the checkout. It loads the existing native Scene3D engineering fixture, checks the exact cinematic source references, resolves scene exposure then shot grain, relocates the original config bytes and reports their hashes. Both effects are **unavailable** until a real backend probe supplies verified support. No image or movie is rendered.

The JSON files are synthetic authoring fixtures, not production art, backend test results or approval. [The contract guide](../../references/cinematics3d-contracts.md) documents units, scope, ownership and the remaining cinematic program requirements.

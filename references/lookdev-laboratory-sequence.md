# Environment, character and animation laboratory

The independent followup command is:

```
python scripts/lookdev_laboratory_sequence.py \
  --output NEW_DIRECTORY --blender /absolute/path/to/Blender4.5 \
  --python-site /absolute/path/to/compatible/BlenderPythonDependencies \
  --temporary-root /absolute/path/to/owned/cache
```

The optional Python site is an operator-selected, trusted dependency installation
compatible with Blender's Python ABI; it is not an asset or shader-code input.
Use the shared native-validation flock in the coordinated host. The runner
freezes trusted scripts, schemas, template and fixed fixture before execution,
uses the frozen adapters, preserves logs on failure, rejects changed host source,
and hashes retained output. The original nine-cell candidate stays separate.

The fixed fixture exercises these parts of mandatory demonstrations B, H and I:

- B: one canonical metallic surface under no environment, exact-source
  self-authored studio HDR and a 90-degree rotation. Actual scene-linear EXR
  differences must exceed .01 average RGB for illumination and rotation.
- H: one versioned engineering character with body and eyes semantic slots,
  rendered in three shots across a studio and warm scene. Exact material
  references, actual polygon-selected material slots and character digest stay
  identical. Every selected datablock must match the separately resolved plan
  and effective material digest; object labels alone cannot pass the check.
  Shots 1/2 share an exact light reference; shot 3 explicitly changes the light.
  Camera changes never rewrite canonical material data.
- I: eight numbered frames at four fps. Absolute frame evaluation translates an
  area light, changes watts and blackbody-inspired temperature, enables material
  emission halfway through, and moves real cube geometry casting shadows. A
  deliberately shuffled render order repeats frame 3; decoded linear float
  pixels must match exactly. Derived frame material/light documents have unique
  identities with exact hashes, preserving source-version immutability.

Every image is actual Cycles output, with a scene-linear EXR and display PNG,
settings, canonical source documents, source snapshot and hashes. The final
editable Blender project retains the last environment experiment; all other
scenes are reproducible from the immutable fixture. These are labeled engineering
fixtures. Numerical gates and source integrity do not supply aesthetic approval.
Actual shadow movement, material placement, character readability, warm-light
response and reflection placement still require visual inspection of the
retained frames. Full demonstrations A, C, D, E, F, G and J, browser parity,
portable roundtrips and full #90 acceptance remain separate release gates.

The separate fixed geometry-shadow experiment uses
`python scripts/lookdev_laboratory_experiments.py shadows` with the same
`--output`, `--blender`, `--python-site` and `--temporary-root` arguments.
It renders clear/occluded controls under small and large area emitters, a moved
emitter, two occluder elevations, ground contact, changed source distance, sun
and spot sources. The occluding cube is hidden from camera rays while remaining
visible to shadow rays. Shadow-only diagnostics are measured attenuation ratios
of actual linear EXR illumination; they are not an input texture. Separate
checks require wider penumbrae with increased angular size, reversed shadow
centroid with reversed source position, increased displacement with elevation,
near-zero contact visibility, and reduced displacement with increased distance.
These checks apply to this fixed geometry and source setup. They need actual
execution and visual inspection before demonstration C can be accepted.
